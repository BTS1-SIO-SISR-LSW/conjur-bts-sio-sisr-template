# Sujet étudiant – CyberArk Conjur Community

## Contexte professionnel
Vous administrez une petite infrastructure disposant de serveurs web et d'équipements réseau.
L'objectif est de centraliser les secrets techniques dans Conjur et de limiter leur accès aux seules machines autorisées.

## Travail demandé
1. Démarrer la stack Docker.
2. Identifier les composants de l'architecture.
3. Initialiser le CLI Conjur.
4. Charger la policy `policy-webservers.yml`.
5. Injecter les secrets requis.
6. Expliquer le rôle des objets `host`, `layer`, `variable` et `permit`.
7. Ajouter un nouveau serveur `web-03` dans la policy.
8. Expliquer comment appliquer le principe du moindre privilège.
